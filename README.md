# Google Business Profile API Integration

A Spring Boot application that integrates with the Google Business Profile API using OAuth 2.0 authentication.

## Features
- Google OAuth 2.0 Login
- Secure Access Token Generation
- Google Business Profile API Integration
- Spring Security OAuth2 Client
- REST API Implementation
- Maven-based Spring Boot Project

## Tech Stack
- Java 21
- Spring Boot
- Spring Security
- OAuth2 Client
- Maven
- Google Cloud Platform
- Google Business Profile API
